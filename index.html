Desafio 01 — Bisneto

O objetivo deste desafio é colocar em prática o que aprendemos nas primeiras aulas de Desenvolvimento Web. Através de pequenas modificações na página, podemos entender melhor a estrutura do HTML, o uso do CSS e a integração com JavaScript.

Como entregar

Regras

  1. Proibido commitar na branch main.
  2. Trabalhar sempre em uma branch própria.
  3. Entregar apenas via Pull Request (PR).

Dica: use mensagens de commit objetivas, por exemplo: feat: ajustar título ou style: melhorar espaçamento.

Tarefas

Complete o máximo de melhorias possível. Cada item concluído e validado no PR soma 1 ponto.

  • Atualizar textos e estruturas da página usando HTML.
  • Adicionar elementos básicos (lista, link, imagem, tabela) de forma organizada.
  • Fazer um ajuste simples de estilo no CSS (cores, fonte, espaçamento).
  • Implementar uma interação simples com JavaScript (nível iniciante).

Critério: a mudança precisa ser visível e fazer sentido. “Mudanças aleatórias” podem não ser pontuadas.

Entrega

  1. Faça um fork do repositório (se estiver usando o fluxo de fork).
  2. Crie uma branch própria: git checkout -b feat/seu-nome.
  3. Implemente uma ou mais melhorias e faça commits.
  4. Envie sua branch: git push -u origin feat/seu-nome.
  5. Abra um Pull Request descrevendo exatamente o que você fez.

No texto do PR, informe os itens que você concluiu (ex.: “Concluí 3 melhorias: título, lista de regras e tabela de pontos”).

Para testar localmente, você pode abrir o index.html no navegador ou usar um servidor local simples.
